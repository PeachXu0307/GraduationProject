The 13-node feeder includes a 115/4.16 kV substation transformer, three single-phase regulators, a 4.16/0.48 kV transformer, delta and wye loads, capacitors, and single-, two-, and three-phase lines. OpenDSS exposes 16 bus names here because source and regulator connection buses are included. The canonical DSS file is not edited by data generation.
